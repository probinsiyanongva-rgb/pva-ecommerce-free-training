Creating & Maintaining Product Listings

This module turns the product data from Module 2 into a real, publishable listing -- and teaches you to catch the errors that slip through before a customer ever sees them.

You do it at Everfield's listing desk on a Wednesday: a listing to build from its record, images and a description to check, and a QA queue before anything goes live. Every line traces to the approved record, or it stays off.

Scope note: This module covers basic keyword awareness only -- writing titles and descriptions with the obvious terms a customer would actually search for. It does not cover advanced SEO strategy, which sits outside this Foundation.
